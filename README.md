# Cybattler — Native Arcade Recompilation v0.1.0

## Overview

Introducing **Cybattler Native Recomp**, an independent native arcade recompilation project bringing Jaleco's 1993 vertically scrolling mecha shoot-'em-up to modern PC platforms.

Cybattler combines fast-paced shooting, robotic combat, and futuristic environments. This project aims to preserve the original arcade experience while providing native execution on Windows, Linux, and Steam Deck.

## Release Highlights

### Native Arcade Recompilation
- Native recompilation of the original arcade game program.
- Modern PC execution without relying on conventional full-system emulation.
- Preservation of original arcade gameplay and timing.
- Arcade graphics, sprite rendering, and sound compatibility.
- Performance and stability improvements as development progresses.

### Classic Mecha Combat
- Original robotic combat mechanics.
- Directional shooting and close-range attacks.
- Enemy waves, boss encounters, and stage progression.
- Original arcade animations, effects, and soundtrack.
- Preservation of the game's original difficulty and gameplay behavior.

### Modern Gameplay Enhancements
- Save-state support and quick save/load.
- Configurable keyboard and gamepad controls.
- Fullscreen and windowed display modes.
- Original aspect-ratio preservation.
- Integer scaling and optional CRT-inspired effects.
- Modern configuration menus.
- Steam Deck controller integration.

These enhancements are project targets and should be considered available only when confirmed in the distributed builds.

## Target Platforms

**Windows x64**
- Native Windows executable.
- Keyboard and controller support.

**Linux x86-64**
- Native Linux executable.
- AppImage distribution target.

**Steam Deck**
- Native Linux compatibility.
- SteamOS Desktop and Gaming Mode support targets.
- No Proton required for compatible native builds.

## Installation

1. Download the appropriate release package for your platform.
2. Extract the Windows archive or make the Linux AppImage executable.
3. Supply the compatible arcade ROM files required by the project.
4. Launch the game and configure your preferred controls and display settings.

Exact installation instructions depend on the release package.

## ROM Requirements

Users must provide their own legally obtained, compatible Cybattler arcade ROM files.

No copyrighted game ROMs, original graphics, audio assets, or proprietary game data are included.

## Compatibility and Known Limitations

This is a development release. Gameplay accuracy, audio synchronization, save-state reliability, controller support, and performance on physical Windows and Steam Deck hardware require verification.

Please report crashes, graphical issues, audio problems, or gameplay inconsistencies through the project's GitHub Issues page.
